# Student Name Search

This page shows student cards. Each card has a student's name and other details.

Type a name in the search box. The page shows cards with names that match. You can type only part of a name. The search does not care about capital letters. Clear the box to show all the cards again.

You can also click the **Search** button or press **Enter**.

## What I Learned

- How to get elements from a web page using JavaScript.
- How to listen for typing, clicks, and key presses.
- How to compare text without worrying about capital letters.
- How to show or hide cards with JavaScript.
